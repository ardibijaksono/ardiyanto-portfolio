Portofolio proyek

Pilihan proyek administrasi data dan digital systems. Proyek data merupakan latihan mandiri menggunakan data dummy; EquipMaxTV merupakan proyek aplikasi internal yang dikembangkan sebagai solusi pengelolaan peminjaman peralatan.

1. Data E-commerce Order

Menyusun alur input dan profiling, standardisasi nama dan kota, pemeriksaan format email dan ID pesanan, identifikasi status pesanan, serta kalkulasi kuantitas dan nilai pesanan.

600 record, 11 field. 0 Order_ID duplikat, 30 email ditandai untuk ditinjau, dan 143 pesanan berstatus cancelled. Menghasilkan rekap nilai bruto dan pendapatan aktif.

2. Data Customer Data Cleaning

Memeriksa ID duplikat, data kosong, dan pola email. Data sumber dipertahankan; data kosong ditandai untuk tindak lanjut, bukan diisi dengan tebakan. Output: Raw_Data, Validation_Log, Validation_Checklist, Cleaned_Data, dan Summary_Report.

730 record menjadi 700 setelah 30 baris duplikat lanjutan dihapus berdasarkan Record_ID. Data kosong tetap ditandai untuk tindak lanjut.

3. Data PDF-to-Excel Invoice

Merekonstruksi data invoice ke tabel terstruktur, mengubah nilai Rupiah berbentuk teks menjadi angka, menjaga nomor invoice sebagai identifier, dan memeriksa rumus Total = Qty × Unit Price.

400 invoice. 400/400 pemeriksaan aritmetika cocok, 0 ID duplikat, dan 0 baris dengan field kosong pada dataset latihan.

4. Data Customer Database Updating

Merancang proses pencocokan berdasarkan Customer_ID dengan pembaruan terbatas pada Email, Phone, dan Account_Status. Mencakup pemeliharaan field lain, update log, penandaan ID yang tidak ditemukan, serta checklist QA.

800 record dan 180 permintaan perubahan dummy. Proyek ini mendemonstrasikan rancangan alur dan kontrol; hasil akhir QA tidak diklaim terverifikasi.

5. Digital Systems — EquipMaxTV

Aplikasi web internal Maxstream Equipment Control (MEC) untuk membantu pengelolaan inventaris dan peminjaman peralatan produksi. Screenshot menampilkan katalog peralatan, filter status ketersediaan/peminjaman, daftar barang yang dipinjam, serta formulir permintaan dengan pilihan paket dan item.

Prototipe aplikasi yang dikembangkan dengan bantuan AI. Beberapa alur seperti pemindaian QR dan pembuatan PDF masih memerlukan pengujian dan penyempurnaan.
